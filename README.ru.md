# Heroes2dBattleGame

[English version](README.md)

Движок пошаговых тактических боёв в духе Heroes of Might and Magic III и настольных
ролевых игр. Это набор библиотек и сменных адаптеров, которые публикуются в npm
отдельными пакетами со scope `@heroes2dgame`.

Проект в ранней стадии разработки. Опубликованных пакетов пока нет.

## Что умеет движок

- Проводит бой на поле из клеток. Первая реализация — гексы, а квадратные сетки и
  объёмные поля с высотами подключаются через тот же интерфейс топологии поля.
- Описывает существ, предметы, эффекты, способности, наборы правил и сценарии данными в
  паках контента в формате JSON, поэтому новый контент не требует программирования.
- Поддерживает разные механики: отряды или одиночные фигуры, порядок ходов по скорости
  или по инициативе, случайные значения из генератора или настоящие кубики, результат
  которых вводит человек.
- Ведёт полный журнал каждого боя: пошаговый просмотр, откат и ответвления.
- Работает без сервера в одной вкладке браузера или с необязательным сервером боёв, если
  игроки подключаются со своих устройств.
- Считает каждого участника боя безликим актором. Что актору можно и что ему видно,
  решает внешняя политика доступа, а решения за актора принимает агент: человек через
  интерфейс, ИИ или внешний бот.
- Встраивается в другие системы через один контракт: библиотеки можно подключить
  напрямую, встроить клиент через iframe, вызвать сервер по HTTP или написать свой адаптер.

Ядро детерминировано: один и тот же журнал даёт один и тот же результат в браузере, в
Web Worker и в Node.js.

## Пакеты

| Пакет | Описание |
|---|---|
| `@heroes2dgame/hex` | Геометрия гексов: координаты, соседи, расстояния, линии и области |
| `@heroes2dgame/kernel` | Детерминированное ядро боя: состояние, команды, события и интерфейсы расширений |

Новые библиотеки, адаптеры и паки контента будут выходить отдельными пакетами.

## Где что лежит

| Папка | Что в ней |
|---|---|
| `libs/` | Библиотеки, из которых собирается любая конфигурация |
| `adapters/` | Адаптеры к портам, по пакету на технологию |
| `apps/` | Приложения, собранные из библиотек и адаптеров. Не публикуются |
| `packs/` | Паки контента: наборы правил, существа, предметы, эффекты, сценарии |
| `docs/` | Документация архитектуры и архитектурные решения |

## Разработка

Для разработки нужны Node.js 24 или новее и pnpm 12. Опубликованные пакеты поддерживают Node.js 22.12 и новее.

```bash
pnpm install
pnpm check
```

`pnpm check` запускает линтер, проверку типов, проверку зависимостей, проверку пакетов и тесты.
Другие команды:

| Команда | Что делает |
|---|---|
| `pnpm test` | Запускает тесты |
| `pnpm build` | Собирает все публикуемые пакеты |
| `pnpm packages` | Проверяет, что каждый пакет следует правилам для пакетов |
| `pnpm verify-dist` | Проверяет собранные пакеты: publint, поиск типов, загрузку через `import` и `require` |
| `pnpm changeset` | Записывает изменение для следующего выпуска |

Выпуск идёт в CI: когда правки попадают в `main`, Changesets открывает запрос на слияние с новыми версиями,
а после его слияния публикует пакеты в npm.
