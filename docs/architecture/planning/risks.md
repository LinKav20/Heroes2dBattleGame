# Риски

Что может пойти не так и что мы с этим делаем.

Обновлено 6 октября 2026.

Сильнее всего нас беспокоят три вещи: модель эффектов может оказаться сложной для авторов, в ядро может просочиться случайность, а скрытая информация может утечь к тем, кому её видеть нельзя.

| Риск | Чем грозит | Что делаем |
|---|---|---|
| Авторам контента будет трудно разобраться в модели эффектов | Без программиста нужную механику не описать | Набор операций небольшой, и в демо-паках есть примеры. Отдельно делаем визуальный редактор для всего контента: эффекты, способности, предметы, наборы правил и сценарии собираются в нём из готовых блоков, сразу проверяются и тут же запускаются в пробном бою |
| В ядро попадёт код, который даёт разный результат при одинаковом входе | Повтор боя и сетевая игра разойдутся | Линтер запрещает в ядре `Math.random` и текущее время. Тесты проигрывают эталонные журналы и сравнивают хеши |
| Скрытая информация утечёт через события | Сетевая игра станет нечестной | Проекции строятся и для событий, а не только для состояния. Тесты сверяют их с независимой проверкой видимости |
| Зависимости между библиотеками начнут нарушать направление к центру | Добавлять новое станет всё труднее | CI проверяет зависимости автоматически |
| Журнал боя разрастётся | Бой будет медленно загружаться и передаваться | Делаем снимки, потребителю передаём журнал только по запросу, при выгрузке сжимаем его |
| Контракт интеграции изменится несовместимо | У потребителей и сторонних адаптеров всё сломается | У контракта есть версия, а тест сравнивает схемы с сохранёнными в репозитории. Старую версию поддерживаем параллельно, пока потребители не перейдут на новую |
