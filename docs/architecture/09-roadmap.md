# 9. Этапы реализации

Обновлено: 2026-10-03.

Кратко: сначала каркас и ядро, потом бой на экране без сервера, потом полная модель правил, ИИ, редактор и встраивание. Сетевая игра — последней, как отдельный набор адаптеров.

| Этап | Результат | Что можно делать после этапа |
|---|---|---|
| 0. Каркас | Монорепозиторий, пакеты `hex` и `protocol` (базовые схемы), проверка зависимостей и детерминизма в CI | Писать код по правилам |
| 1. Ядро | Загрузка и проверка контента. Состояние, команды, события, стек шагов, запросы решений. Порядок ходов по скорости. Ходьба, атака, выстрел, ожидание, оборона, ответный удар. Урон, лечение, наложение эффекта. Журнал, контрольные точки, откат | Проводить бои в тестах без интерфейса |
| 2. Бой на экране | Прикладной слой с локальным источником истины, хранилищем IndexedDB и каналом в памяти. Проигрыватель событий, отрисовщик PixiJS, интерфейс боя. Профиль `solo` | Мастер проводит бой за обе стороны |
| 3. Полная модель правил | Модификаторы, теги, эффекты с длительностями, наложением и аурами. Триггеры, способности, предметы и зелья, заклинания и герой. Порядок ходов по инициативе, мораль и удача. Набор правил `core:d20-tactical` | Бои в духе Героев и в духе d20 |
| 4. ИИ и история | Простой ИИ в Web Worker, смена агента посреди боя. Просмотр журнала по шагам, ответвления. Симулятор для баланса | Бой против ИИ, разбор боя |
| 5. Сценарии и редактор | Формат сценария, триггеры и условия победы, приложение-редактор с запуском боя | Авторы делают сценарии без программиста |
| 6. Встраивание | Профиль `embedded`, мост postMessage, протокол встраивания, схемы конфигурации и результата, пример хоста | Хосты запускают наши бои у себя |
| 7. Сетевая игра | Сервер боёв, удалённый источник истины, канал WebSocket, срезы по местам, токены мест, серверные боты. Профиль `networked` | Игроки на своих устройствах, мастер наблюдает |
