# Контент

Обновлено: 2026-10-03.

Кратко: всё, из чего состоит бой, описывается в паках контента в формате JSON. Паки проверяются схемами и по смыслу, имеют версии и подключаются в предсказуемом порядке. Определения в бою не меняются, у юнитов хранятся только изменяемые поля.

## Пак

Пак — папка с манифестом `pack.json` и файлами по типам: наборы правил, атрибуты, теги, существа, герои, предметы, способности, заклинания, эффекты, поля боя, препятствия, сценарии, переводы. Пример манифеста — в [reference/examples.md](../../reference/examples.md).

В манифесте указаны идентификатор, версия, версия формата, совместимые версии движка, зависимости от других паков и язык по умолчанию.

## Идентификаторы

- У каждой сущности идентификатор вида `пак:id`, например `demo-homm:archer`. Внутри своего пака можно писать просто `archer`.
- Переименование оформляется через таблицу псевдонимов в манифесте, чтобы старые сценарии и журналы продолжали работать.

## Определения и экземпляры

Определение сущности неизменно. В бою у юнита хранится ссылка на определение и только то, что меняется: количество, здоровье, эффекты, флаги, инвентарь. Сущность может наследовать другую через `extends`; значения копируются при загрузке.

## Порядок загрузки и патчи

- Паки загружаются в порядке зависимостей, при равенстве — по алфавиту. Результат всегда одинаковый.
- Пак может изменить сущность из другого пака отдельной записью-патчем. Элементы списков в патчах адресуются по идентификатору, а не по номеру позиции.
- После загрузки реестр контента замораживается и получает хеш. Журнал боя запоминает паки, их версии и хеш.

## Проверка

Каждый файл проходит три этапа:

1. Миграция формата до текущей версии, по одному шагу за раз.
2. Проверка структуры по схеме. Схемы пишутся на TypeBox и публикуются как JSON Schema 2020-12.
3. Проверка смысла. Существуют ли все упомянутые сущности, нет ли повторов и циклов наследования, зарегистрированы ли все операции и условия, помещаются ли юниты на поле и в зоны расстановки, объявлены ли переменные сценария, есть ли переводы.

Ошибки возвращаются списком: серьёзность, путь к полю, текст. Сломанная сущность пропускается, остальные загружаются.

## Версии

| Версия | Что означает |
|---|---|
| Версия формата файла | Целое число для каждого типа файла. Меняется, когда меняется структура |
| Версия пака | Семантическая версия содержимого |
| Версия движка | Пак указывает, с какими версиями движка совместим |

## Переводы

Текстовые поля хранят ключ перевода или текст по умолчанию. Переводы лежат в файлах по языкам, с запасным языком из манифеста.
