# 7. Требования к качеству

Пять главных качеств, разложенные на конкретные ситуации, которые можно измерить и проверить.

Обновлено 5 октября 2026.

## 7.1 Дерево качества

В последнем столбце две оценки: насколько ситуация важна для продукта и насколько трудна для архитектуры. Шкала такая: В — высокая, С — средняя, Н — низкая. Сильнее всего на архитектуру влияют ситуации с оценкой В/В.

| Качество | Что именно | Ситуация | Оценка |
|---|---|---|---|
| Воспроизводимость | Повтор боя | К-1 | В/В |
| Воспроизводимость | Одинаковый результат в разных средах | К-2 | В/С |
| Расширяемость | Новый адаптер | К-3 | В/В |
| Расширяемость | Новое правило | К-4 | В/С |
| Автономность | Работа без сети | К-5 | В/С |
| Автономность | Продолжение после перезагрузки | К-6 | В/Н |
| Честность | Проверка команд | К-7 | В/С |
| Честность | Скрытая информация | К-8 | С/В |
| Встраиваемость | Запуск из хоста | К-9 | В/С |
| Отзывчивость | Подсказки | К-10 | С/С |
| Отзывчивость | Задержка в сети | К-11 | С/С |

## 7.2 Ситуации

| № | Что происходит | Где | Что должно получиться | Как измеряем |
|---|---|---|---|---|
| К-1 | Разработчик заново проигрывает журнал завершённого боя | Ядро | То же итоговое состояние | Хеши совпадают для всех эталонных журналов в CI |
| К-2 | Один журнал проигрывается в браузере, в Web Worker и в Node.js | Ядро | Одинаковое состояние | Хеши совпадают во всех трёх средах |
| К-3 | Разработчик добавляет новое хранилище или транспорт | Адаптеры | Ядро, прикладная логика и протокол не меняются | Правки только в новом пакете и в профиле; адаптер проходит общие тесты порта |
| К-4 | Автор добавляет существо с новым сочетанием эффектов | Контент | Всё работает без правок кода | Изменён только JSON, проверка контента проходит |
| К-5 | Бой проходит на одном устройстве без сети | Веб-клиент | Бой проходит от начала до конца | После загрузки клиента и паков нет ни одного сетевого запроса |
| К-6 | Вкладка закрылась посреди боя | Веб-клиент | Бой продолжается с последнего шага | Теряется не больше одной незавершённой команды |
| К-7 | Актор отправляет недопустимую команду | Арбитр | Команда отклонена, состояние не изменилось | В тестах на случайных партиях отклоняются все недопустимые команды |
| К-8 | Актор с ограниченной областью видимости получает пакеты событий | Сервер | Скрытое от него не попадает ни в проекцию, ни в события | Независимая проверка видимости не находит утечек |
| К-9 | Разработчик хоста встраивает бой по документации | Протокол встраивания | Бой запускается и возвращает результат | Пример хоста работает, не обращаясь к нашему коду |
| К-10 | Человек наводит курсор на гекс | Веб-клиент | Подсветка и прогноз появляются сразу | Подсказка считается не дольше 16 мс при 40 юнитах на поле |
| К-11 | Актор отправляет команду в сетевом бою | Сервер и клиент | Анимация результата начинается быстро | От отправки команды до начала показа не больше 300 мс при задержке сети 100 мс |
