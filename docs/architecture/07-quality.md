# 7. Требования к качеству

Обновлено: 2026-10-03.

Кратко: дерево качества раскладывает пять целей качества на конкретные сценарии. У каждого сценария есть измеримый критерий и способ проверки.

## 7.1 Дерево качества

Оценки: важность для продукта / сложность для архитектуры, по шкале высокая (В), средняя (С), низкая (Н). Сценарии с оценкой В/В определяют архитектуру сильнее остальных.

| Качество | Уточнение | Сценарий | Оценка |
|---|---|---|---|
| Воспроизводимость | Повтор | К-1 | В/В |
| Воспроизводимость | Одинаковость сред | К-2 | В/С |
| Расширяемость | Новый адаптер | К-3 | В/В |
| Расширяемость | Новое правило | К-4 | В/С |
| Автономность | Работа без сети | К-5 | В/С |
| Автономность | Восстановление после перезагрузки | К-6 | В/Н |
| Честность | Проверка команд | К-7 | В/С |
| Честность | Скрытая информация | К-8 | С/В |
| Встраиваемость | Запуск из хоста | К-9 | В/С |
| Отзывчивость | Подсказки | К-10 | С/С |
| Отзывчивость | Сетевая задержка | К-11 | С/С |

## 7.2 Сценарии качества

| № | Источник и событие | Где | Ожидаемая реакция | Критерий |
|---|---|---|---|---|
| К-1 | Разработчик повторяет журнал завершённого боя | Ядро | Получено то же итоговое состояние | Хеш совпадает для 100% эталонных журналов в CI |
| К-2 | Один журнал повторяется в браузере, Web Worker и Node.js | Ядро | Состояния одинаковы | Хеши совпадают во всех трёх средах |
| К-3 | Разработчик добавляет новое хранилище или транспорт | Адаптеры | Ядро, прикладной слой и протокол не меняются | Изменения только в новом пакете и в профиле; адаптер проходит контрактные тесты порта |
| К-4 | Автор добавляет новое существо с новым сочетанием эффектов | Контент | Работает без изменений кода | Только JSON; проверка контента проходит |
| К-5 | Мастер проводит бой без сети | Веб-клиент | Бой проходит от начала до конца | Ни одного сетевого запроса после загрузки клиента и паков |
| К-6 | Вкладка закрылась посреди боя | Веб-клиент | Бой продолжается с последнего шага | Потеряна не больше чем последняя незавершённая команда |
| К-7 | Участник отправляет недопустимую команду | Источник истины | Команда отклонена, состояние не изменилось | 100% недопустимых команд в тестах на случайных партиях отклоняются |
| К-8 | Игрок в сетевом бою получает пакеты событий | Сервер | Скрытое от игрока не попадает ни в срез, ни в события | Независимая проверка видимости не находит утечек |
| К-9 | Хост встраивает бой по документации | Протокол встраивания | Бой запускается и возвращает результат | Пример хоста работает без обращения к нашему коду |
| К-10 | Мастер наводит курсор на гекс | Веб-клиент | Подсветка и прогноз появляются сразу | Не больше 16 мс на подсказку при 40 юнитах на поле |
| К-11 | Игрок отправляет команду в сетевом бою | Сервер и клиент | Результат начинает проигрываться | Не больше 300 мс от отправки до начала показа при задержке сети 100 мс |
