# 8. Риски и открытые вопросы

Обновлено: 2026-10-03.

Кратко: главные риски — сложность модели эффектов, нарушение детерминизма и утечка скрытой информации. Открытые вопросы касаются правил отрядов в d20, видимости и протокола встраивания.

## 8.1 Риски

| Риск | Последствия | Что делаем |
|---|---|---|
| Модель эффектов окажется слишком сложной для авторов контента | Авторы не смогут описать нужные механики без программиста | Начинаем с небольшого набора операций; редактор с формами по схемам и предпросмотром; примеры в демо-паках |
| В ядро попадёт недетерминированный код | Повтор и сетевая игра расходятся | Запрет `Math.random` и времени в ядре линтером; эталонные журналы и сравнение хешей в CI во всех средах |
| Скрытая информация утечёт через события | Нечестная игра в сети | Срезы для событий, а не только для состояния; тесты с независимой проверкой видимости |
| Правила зависимостей начнут нарушаться | Расширяемость деградирует | Автоматическая проверка зависимостей в CI |
| Журнал боя станет большим | Медленная загрузка и передача | Контрольные точки; журнал хосту — только по запросу; сжатие при выгрузке |
| Протокол встраивания изменится несовместимо | Хосты сломаются | Версия протокола в `ready`; поддержка старой версии ограниченное время |

## 8.3 Открытые вопросы

| Вопрос | Варианты | Когда решать |
|---|---|---|
| Как считается атака отряда в наборе правил d20 | Один бросок на отряд и урон по числу существ; бросок на каждое существо; урон по таблице | До реализации `core:d20-tactical` |
| Нужна ли видимость (туман войны) уже на первых этапах | Сразу; позже, когда появится сетевая игра | До этапа сетевой игры |
| Может ли хост передавать собственный контент (своих существ и предметы), а не только параметры | Только параметры к нашим сценариям; встроенный пак от хоста | До этапа встраивания |
| Как хранить журналы в браузере долго | Хранить всё; удалять старые бои по сроку; выгружать хосту и удалять | До этапа встраивания |
| Нужен ли перенос локального боя на сервер посреди боя | Нужен; не нужен, сетевой бой создаётся сразу на сервере | До этапа сетевой игры |
