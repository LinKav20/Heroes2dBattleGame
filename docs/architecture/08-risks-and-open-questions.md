# 8. Риски и открытые вопросы

Что может пойти не так и что мы ещё не решили.

Обновлено 5 октября 2026.

Сильнее всего нас беспокоят три вещи: модель эффектов может оказаться сложной для авторов, в ядро может просочиться случайность, а скрытая информация может утечь к тем, кому её видеть нельзя.

## 8.1 Риски

| Риск | Чем грозит | Что делаем |
|---|---|---|
| Авторам контента будет трудно разобраться в модели эффектов | Без программиста нужную механику не описать | Начинаем с небольшого набора операций. В редакторе формы строятся по схемам и сразу показывают итоговые характеристики. В демо-паках есть примеры |
| В ядро попадёт код, который даёт разный результат при одинаковом входе | Повтор боя и сетевая игра разойдутся | Линтер запрещает в ядре `Math.random` и текущее время. CI проигрывает эталонные журналы во всех средах и сравнивает хеши |
| Скрытая информация утечёт через события | Сетевая игра станет нечестной | Проекции строятся и для событий, а не только для состояния. Тесты сверяют их с независимой проверкой видимости |
| Правила зависимостей начнут нарушать | Добавлять новое станет всё труднее | CI проверяет зависимости автоматически |
| Журнал боя разрастётся | Бой медленно загружается и передаётся | Снимки; хосту журнал отдаём только по запросу; при выгрузке сжимаем |
| Протокол встраивания изменится несовместимо | У хостов всё сломается | Клиент сообщает версию протокола в `ready`. Старую версию поддерживаем ещё какое-то время |

## 8.3 Открытые вопросы

| Вопрос | Варианты | Когда решить |
|---|---|---|
| Как считать атаку отряда по правилам d20 | Один бросок на отряд, урон по числу существ; бросок на каждое существо; урон по таблице | До реализации `core:d20-tactical` |
| Нужен ли туман войны на первых этапах | Сразу; когда появится сетевая игра | До сетевой игры |
| Может ли хост присылать своих существ и предметы, а не только параметры к нашим сценариям | Только параметры; разрешить хосту свой пак | До этапа встраивания |
| Как долго хранить журналы в браузере | Хранить всё; удалять старые бои по сроку; отдавать хосту и удалять | До этапа встраивания |
| Нужно ли переносить бой без сервера на сервер прямо посреди боя | Нужно; не нужно, сетевой бой сразу создаётся на сервере | До сетевой игры |
