# Справочник

Обновлено: 2026-10-03.

Точные форматы и наброски типов. Здесь нет объяснений, они в [описании архитектуры](../architecture/README.md).

Сейчас это наброски. Когда появится пакет `protocol`, источником правды станут схемы TypeBox и выгруженные из них JSON Schema, а эти файлы будут ссылаться на них.

| Файл | Что внутри |
|---|---|
| [types.md](types.md) | Порты, ядро, модель правил, состояние, команды, события |
| [protocol.md](protocol.md) | Протокол боя (участники и источник истины) и протокол встраивания (хост и клиент) |
| [examples.md](examples.md) | Примеры JSON: манифест пака, сценарий, конфигурация и результат боя, встраивание на стороне хоста |
