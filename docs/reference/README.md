# Справочник

Точные форматы данных, наброски типов и примеры. Объяснений здесь нет, они в [описании архитектуры](../architecture/README.md).

Обновлено 5 октября 2026.

Пока это наброски. Когда появится пакет `protocol`, точными станут схемы TypeBox и выгруженные из них JSON Schema, а эти файлы будут ссылаться на них.

| Файл | Что внутри |
|---|---|
| [types.md](types.md) | Порты, ядро, модель правил, состояние, команды и события |
| [protocol.md](protocol.md) | Протокол боя между акторами и арбитром, протокол встраивания между хостом и клиентом, HTTP API сервера |
| [examples.md](examples.md) | Примеры: манифест пака, сценарий, конфигурация и результат боя, код встраивания на стороне хоста |
