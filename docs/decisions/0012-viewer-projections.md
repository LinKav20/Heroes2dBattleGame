# 0012. Срезы для зрителей и для состояния, и для событий

Чтобы скрытое не утекало к игрокам и ИИ не жульничал, мы строим срез для каждого зрителя и для состояния, и для каждого пакета событий у источника истины, принимая дополнительную работу при каждой рассылке.

## Контекст и проблема

Мастер должен видеть всё, игрок — только своё и разрешённое правилами. Скрытое может утечь не только через состояние, но и через события, например через координаты в событии перемещения.

## Рассмотренные варианты

1. Отправлять всем полное состояние, скрывать в интерфейсе. Скрытое доступно в инструментах разработчика.
2. Фильтровать только состояние. Утечки через события.
3. Фильтровать и состояние, и события у источника истины перед отправкой.

## Решение

Мы выбираем третий вариант. Появление и исчезновение скрытого — отдельные события. ИИ получает срез своей стороны.

## Последствия

- Хорошо: честная сетевая игра; честный ИИ.
- Плохо: каждый пакет фильтруется для каждого зрителя.

## Как проверяем

Тесты на случайных партиях с независимой проверкой видимости.
