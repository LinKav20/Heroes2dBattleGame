# 0011. Юнит — отряд с количеством

Чтобы поддержать и отряды Героев, и одиночные фигуры d20 без развилок в ядре, мы храним у юнита количество существ и здоровье верхнего, а одиночное существо считаем отрядом из одного, принимая, что формулы урона для отрядов задаёт набор правил.

## Контекст и проблема

В Героях юнит — отряд: урон зависит от числа существ, потери считаются по здоровью. В d20 каждая фигура отдельная.

## Рассмотренные варианты

1. Два вида юнитов. Развилки во всех правилах.
2. Только отряды, одиночное существо — отряд из одного.

## Решение

Мы выбираем второй вариант. У юнита: количество существ и здоровье верхнего. Как численность влияет на атаку и урон, задаёт набор правил.

## Последствия

- Хорошо: одна модель для обоих стилей.
- Плохо: формула атаки отряда для d20 пока не определена (открытый вопрос).

## Как проверяем

Тесты урона и потерь для отрядов разной численности и для одиночных существ.
