# 0016. Схемы на TypeBox с экспортом в JSON Schema

Чтобы типы TypeScript и проверка данных не расходились, а схемы могли использовать хосты на любом языке, мы пишем схемы на TypeBox и экспортируем их в JSON Schema 2020-12, принимая зависимость от TypeBox.

## Контекст и проблема

Контент, конфигурация и результат боя, сообщения протокола проверяются на входе. Хосты должны знать точный формат. Типы в коде должны совпадать со схемами.

## Рассмотренные варианты

1. Ручные типы и ручная проверка. Расходятся.
2. Zod. Удобен, но преобразования не выражаются в JSON Schema.
3. TypeBox: схема и есть JSON Schema, типы выводятся из неё.

## Решение

Мы выбираем TypeBox. Схемы живут в пакете `protocol`. Сборка выгружает JSON Schema 2020-12 как опубликованный артефакт.

## Последствия

- Хорошо: один источник для типов, проверки и документации формата.
- Плохо: зависимость от библиотеки.

## Как проверяем

CI сравнивает выгруженные схемы с закоммиченными; изменения схем видны в ревью.
