# Список решений

Архитектурные решения проекта, по одному в файле.

Обновлено 9 октября 2026.

Каждое решение оформляется по [шаблону](template.md).

| № | Решение | Коротко | Статус |
|---|---|---|---|
| [0001](0001-language-independence.md) | Независимость от языка и разные реализации | Границы описаны схемами JSON Schema; первая реализация на TypeScript, любую часть можно написать на другом языке, правила реализаций могут отличаться | Принято |
| [0002](0002-ports-adapters-microkernel.md) | Порты, адаптеры и микроядро | Ядро и прикладная логика обращаются к внешнему миру через порты, расширения подключаются через реестры, границы проверяет CI | Принято |
| [0003](0003-deterministic-kernel.md) | Детерминированное ядро и ввод через запросы | Одно ядро для браузера, сервера, ИИ и тестов; внешний ввод — запрос в состоянии, броски генератора ядро делает само | Принято |
| [0004](0004-event-journal.md) | История боя — журнал событий | Просмотр, откат и проверка без повторного расчёта правил | Принято |
| [0005](0005-arbiter-and-access.md) | Один арбитр, безликие акторы с агентами и внешняя политика доступа | Клиент работает без сервера; права, видимость и роли решает внешняя политика, а решения за актора принимает сменный агент | Принято |
| [0006](0006-content-and-rules-as-data.md) | Контент и правила описываются данными | Паки в JSON, операции из реестра, модель правил, наборы правил, отряды, схемы JSON Schema, визуальный редактор | Принято |
| [0007](0007-event-driven-presentation.md) | Экран проигрывает события, а оформление описано отдельно | Ядро и контент не знают об экране; рендерер можно заменить, анимации можно пропустить | Принято |
| [0008](0008-integration-contract.md) | Интеграция через контракт и сменные адаптеры | Один контракт для всех потребителей; прямое подключение или адаптер: iframe, HTTP, свой | Принято |
| [0009](0009-battle-server.md) | Сервер боёв — одно приложение, первая реализация на Node.js | Тот же код ядра, без микросервисов; свой сервер на любом языке может написать кто угодно | Принято |
| [0010](0010-content-naming-and-versions.md) | Имена, версии и совместимость контента | Имена `пак:имя` с псевдонимами, семантические версии паков, неизменные опубликованные версии, хеш контента без текстов | Принято |
| [0011](0011-packages-and-license.md) | Отдельные пакеты в npm под некоммерческой лицензией | Библиотеки, адаптеры и паки — отдельные пакеты `@heroes2dgame/*` со своими версиями; PolyForm Noncommercial 1.0.0, для коммерческого использования — платная лицензия | Принято |
