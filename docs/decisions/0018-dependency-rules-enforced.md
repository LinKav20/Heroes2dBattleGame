# 0018. Правила зависимостей проверяются автоматически

Чтобы архитектура не деградировала незаметно, мы проверяем правила зависимостей и детерминизм в CI, принимая время на настройку проверок.

## Контекст и проблема

Правила вида «ядро ни от чего не зависит» и «адаптеры не зависят друг от друга» легко нарушить случайным импортом. На ревью это пропускают.

## Рассмотренные варианты

1. Полагаться на ревью. Нарушения накапливаются.
2. Автоматические проверки в CI.

## Решение

Мы выбираем автоматические проверки:

- dependency-cruiser: направления зависимостей между пакетами и отсутствие циклов;
- ESLint: запрет `Math.random`, `Date.now`, DOM и API Node в ядре;
- проверка состава сборок: в сервере нет React и PixiJS, в клиенте нет драйвера PostgreSQL;
- повтор эталонных журналов в браузере, Web Worker и Node.js со сравнением хешей;
- контрактные тесты для каждого порта.

## Последствия

- Хорошо: нарушения ловятся до слияния.
- Плохо: проверки нужно поддерживать вместе со структурой пакетов.

## Как проверяем

Проверки входят в обязательный набор CI.
