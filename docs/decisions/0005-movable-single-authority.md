# 0005. Один источник истины на бой, локальный по умолчанию

Чтобы клиент работал без сервера, а сетевая игра подключалась без переделки, мы делаем источник истины портом: по умолчанию он локальный, в клиенте, а при подключении сервера переезжает на сервер. Принимаем, что в каждый момент команды принимает только один источник.

## Контекст и проблема

Мастер может вести бой один на одном устройстве и транслировать экран. А может быть сетевой бой, где мастер, игроки и боты сидят на своих устройствах. В обоих случаях нужны проверка команд, единый порядок ходов и честные броски.

## Рассмотренные варианты

1. Всегда сервер. Клиент без сервера не работает.
2. Каждый клиент считает сам и обменивается командами (lockstep). Нельзя скрыть информацию, любое расхождение ломает игру.
3. Слияние правок от всех участников (CRDT). Не сохраняет правила: порядок ходов, допустимость действий, броски.
4. Один источник истины на бой, местоположение которого выбирается адаптером.

## Решение

Мы выбираем четвёртый вариант. Порт `Authority` имеет локальный адаптер (выполняет ядро в клиенте) и удалённый (через канал к серверу). Остальные копии — реплики: только применяют события. Смена источника истины повышает эпоху; команды со старой эпохой отклоняются. Локальное хранилище — IndexedDB.

## Последствия

- Хорошо: клиент полностью автономен; сервер — новый адаптер, а не переделка.
- Хорошо: в сети генератор случайных чисел и скрытое состояние не покидают сервер.
- Плохо: каждое действие в сети ждёт ответа сервера. Для пошаговой игры приемлемо.

## Как проверяем

Одни и те же сценарные тесты прогоняются с локальным и удалённым источником истины. Тест: команда со старой эпохой отклоняется.
