# Как внести вклад

[English version](CONTRIBUTING.md)

Спасибо, что помогаете Heroes2dBattleGame. Здесь описано, как подготовить репозиторий, сделать
правку и довести её до слияния.

## Перед началом

- Правки принимаются только с подписанным [соглашением контрибьютора](CLA.md). Проверка CLA
  предложит подписать его в первом запросе на слияние.
- Перед большой правкой откройте issue, чтобы сначала договориться о подходе.
- Об уязвимостях сообщайте закрыто, а не в публичном issue. Подробнее — в [SECURITY.md](SECURITY.md).

## Подготовка

Для разработки нужны Node.js 24 или новее и pnpm 12.

```bash
pnpm install
pnpm check
```

`pnpm check` запускает линтер, проверку типов, проверку зависимостей, проверку пакетов и тесты.
Стиль кода проверяет линтер, поэтому зелёный `pnpm check` значит, что со стилем всё в порядке.

## Как сделать правку

1. Создайте ветку от `main`.
2. Внесите правку. Тесты кладите в папку `tests` рядом с кодом, который они проверяют.
3. Запустите `pnpm check`.
4. Если правка меняет публикуемый пакет, запустите `pnpm changeset` и опишите изменение для
   журнала изменений. Правкам тестов и документации changeset не нужен.
5. Откройте запрос на слияние. CI повторит проверки и соберёт пакеты.

Код, комментарии и README пакетов пишутся на английском. Документация архитектуры в
[docs/](docs/README.md) — на русском.
