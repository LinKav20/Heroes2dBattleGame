# Временные моки и визуальные референсы

Эта папка содержит временные концепты, изображения и интерактивные моки. Они нужны только для предварительной оценки играбельности: читаемости поля боя, размеров участников, плотности расстановки, перемещения, препятствий и заметности эффектов действий.

Материалы помогают обсуждать и проверять идеи. Они не являются продакшен-решением, готовыми игровыми ассетами или спецификацией боевых правил. Код макетов демонстрирует поведение и не предназначен для переноса в игровой движок без отдельного проектирования.

## Что делать при реализации продакшен-решения

- Реализовать утверждённые решения в основной архитектуре проекта и подготовить финальные игровые ассеты.
- Перенести нужные выводы и требования в актуальную документацию проекта.
- Удалить всю папку `tmp/mocks` вместе с моками, референсами, изображениями, скриншотами, промптами и вспомогательным кодом. Удалить также ссылки и зависимости от этих материалов.

Эти материалы не должны попадать в продакшен-сборку или оставаться постоянной частью реализации.

## Содержимое

- `2026-10-03/` — первые визуальные концепты и галерея.
- `2026-10-03/battle-review/` — интерактивная раскадровка боя, эффекты действий и проверки компоновки.
